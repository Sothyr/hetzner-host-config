# Rules for this repository

- All design and all UI components are based on Material Design (https://m3.material.io).
  Use Material Web components (`@material/web`, registered in `frontend/src/material.ts`)
  and Material tokens before writing custom controls. Steps and tab-like navigation use
  Material tabs (`md-tabs` with `md-primary-tab` or `md-secondary-tab`). If there is non use Bootsrap 5 (https://getbootstrap.com/docs/6.0/getting-started/install/)
- Short answers, no em-dashes, verify APIs instead of guessing.

- Use CleanCode pattern and refactor if it is not used
- Components, no "Spagetti-Code"
- make Implementations Reusable, like an library
